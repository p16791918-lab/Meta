# Full-text reclassification log — author-supplied PDFs

Record of the close PDF read of 17 full texts the author obtained (GitHub upload,
commit affc2fa), plus the 3 that remain unobtained. Each entry states what the
source actually reports and the resulting decision. Decisions favour keeping the
main analysis unchanged (no new arbitrary computed overlaps) unless the source
adds a genuinely new, independent, NHW-comparable estimate.

## Verified (already extracted; source now available)

  cells. Every extracted subtype IRR reproduced verbatim from the main text:
  Black TNBC 2.07 (2.01–2.14), HR−/HER2+ 1.46, HR+/HER2+ 1.12, HR+/HER2− 0.86;
  Asian/PI HR−/HER2+ 1.41, HR+/HER2− 0.87, TNBC 0.79; Hispanic 0.78 / 0.91 / 0.94.
  **Decision: verified, no change.** (Closes the last no-PDF main-rep gap except rec 155.)

## Quantitatively eligible but deferred (extractable yet redundant) — kept deferred
Each reports breast data but overlaps a study already represented, so extracting
it would only add a non-independent overlap to the sensitivity pool (no new cell).
- **rec 209 — TNBC AAIR by race 2011–2019 (USCS).** Overlaps rec 155/142 (same
  USCS TNBC-by-race source). Deferred.
- **rec 419 — TNBC + overall, young African American, CCR 1988–2006.** Age-restricted
  ("young"), which the synthesis excludes from all-age cells; also overlaps CCR. Deferred.
- **rec 2137 — urban AI/AN vs NHW, 1999–2017.** A multi-cancer disparities paper;
  breast is one site among many and is not given as a standalone AI/AN-vs-NHW breast
  rate. Overlaps existing AI/AN. Deferred.
- **rec 4027 — 6 Asian subgroups vs NHW, SEER+NPCR 2009–2011.** Reports all-cancer
  (not breast-specific) subgroup rates in the extractable text; overlaps rec 234/4098
  (the AANHPI subgroup representatives). Deferred.

## Narrative — confirmed (no recoverable NHW-comparable incidence estimate)

- **rec 46 — subtype incidence by race, SEER22; APC/trend.** Trend-dominant.
- **rec 119 — Michigan AI, IHS-linked.** Reports all-cancer rates (405.5 / 513.9 for

  small numbers.
- **rec 142 — TNBC NHB, regional.** Comparator is a region, not a recoverable NHW rate.
- **rec 145 — Wisconsin AA vs white, 1995–2006.** Disparity is shown as trends/figure;

- **rec 210 — SEER18 Asian trends, 2000–2019.** *Does* report aggregate breast rates by

  broader-coverage USCS representative (rec 169), so rec 210 would be a demoted overlap
  only. **Kept narrative** to avoid adding a non-independent computed overlap that
  changes nothing (and to avoid a further "computed ratio" objection).
- **rec 226 — redlining/mortgage-discrimination exposure study.** Reports %-of-cases by
  subtype (TNBC 26.2% NHB vs 11.8% NHW), i.e., proportions, not incidence rates.
- **rec 246 — CCR breast by race + SES, 1998–2002.** No extractable race-specific breast
  rate with a White comparator located in the text; overlaps CCR.
- **rec 252 — hormone-therapy commentary; PIR/trend.** Commentary, non-standard metric.
- **rec 259 — inflammatory breast carcinoma by race, SEER.** A niche subtype outside the
  HR/HER2/TNBC set; no new receptor-defined cell.
