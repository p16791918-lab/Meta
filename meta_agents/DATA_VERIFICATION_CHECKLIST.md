# Data verification checklist — values entering the meta-analysis

For each included study, confirm every extracted rate against the cited
table/figure in the primary full text, then tick the box. IRR is computed
= minority_rate / nhw_rate. Rows marked '(from CI/counts)' were entered as a
log-IRR + SE (no raw rates) — verify the reported rate ratio / CI instead.
